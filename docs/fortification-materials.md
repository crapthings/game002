# 城防材质与城门 polish

城门修正了埋在石墩内的门扇、方向错误的圆柱门钉、没有贴合坡面的瓦垄与屋顶顶部开口。新增铁箍、铜环、铰链、石墩收边、拱顶锁石、城台石栏、灯笼吊架/流苏、牌匾边框与山形纹章。拱券保留贯通门洞，以楔形切石与细接缝表达承重结构。屋面增加 0.16 米厚度。

`createFortificationMaterials` 提供四组 256×256 的共享颜色/法线纹理：错缝青砖、切石微颗粒、纵向木纹、瓦面。生成发生在材质第一次使用时，后续城墙、城门和角楼复用；资产注册表销毁时统一释放。UV 按模型米制坐标生成，避免尺寸不同的石块把纹理拉伸；自定义拱券与屋面同样补齐 UV。

使用 Babylon StandardMaterial 的现有着色器路径处理法线贴图和高光，不增加自定义 shader、逐帧噪声计算、视差映射或逐砖实体。石材低高光、木材柔和高光、瓦面较集中高光、铜件较强高光。法线贴图使用线性色彩空间；重复纹理使用 mipmaps、三线性采样和 4× 各向异性过滤。四组 RGBA 颜色/法线纹理含 mipmaps 理论约 2.7 MiB，不含引擎额外分配。

细节仍按材质合并进模板后实例化，未为每块砖增加 draw call。没有进行 GPU 性能实测，不宣称帧率提升。后续如需更明显的湿润、雨痕或昼夜材质变化，再评估材质插件；当前无需单独维护自定义着色器。

验证：JavaScript 语法与 diff 检查；浏览器资产目录预览城门的纹理、门扇和整体轮廓。遵循 AGENTS.md，未运行测试、build、lint。
