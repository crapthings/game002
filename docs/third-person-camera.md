# 第三人称与可视范围

游戏使用透视跟随相机，初始位于角色后方 6 米。WASD / 方向键按镜头方向移动，Shift 奔跑，左键拖动环绕，滚轮在 2.5–10 米之间调整镜头距离；左键不控制角色移动。暂停、打开面板或失焦会清空操作状态。镜头以地形和场景素材射线检测收近避障。

Esc 暂停菜单的「图形配置」提供 32–160 米可视范围滑杆，步长 16 米，默认 64 米。设置即时生效，并独立保存在 game002:graphics:v1 中。

范围同步驱动相机远裁剪、远景雾和自然地形区块需求。区块按 32 米粒度加载，额外保留一圈禁用缓存，超出后分帧释放。移动碰撞通过区块障碍物包围盒排除远处候选。

本阶段只保留自然资产与侠客。世界已调整为 512×512 米，武侠内容尚待后续改造。全局世界规划和素材模板预热仍然存在，可视范围控制的是运行时附近区块与实体。
