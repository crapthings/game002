# 第三人称与可视范围

游戏使用透视跟随相机，初始位于角色后方 6 米。WASD / 方向键按镜头方向移动，Shift 奔跑，右键拖动环绕，滚轮在 2.5–10 米之间调整镜头距离；保留左键地面寻路。暂停、打开面板或失焦会清空操作状态。镜头以地形和场景素材射线检测收近避障。

Esc 暂停菜单的「图形配置」提供 32–160 米可视范围滑杆，步长 16 米，默认 64 米。设置即时生效，并独立保存在 game002:graphics:v1 中。

范围同步驱动相机远裁剪、远景雾、地形区块需求及实体准备范围。区块按 32 米粒度加载，并预留镜头偏移覆盖；额外保留一圈禁用区块，防止边界反复加载，超出后分帧释放。实体准备最多 64 米、活动数量最多 32，沿用原有昼夜可见性规则；出生点按空间桶筛选。移动碰撞通过区块障碍物包围盒排除远处候选。

此次保留全部素材及原有世界生成、存档和玩法。世界已调整为 512×512 米，武侠内容尚待后续改造。全局世界规划和素材模板预热仍然存在，可视范围控制的是运行时附近区块与实体。
