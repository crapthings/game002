# 第一批城内 NPC

角色目录加入布衣男子、素衣女子、摊贩、挑担货郎、巡城衙役五个模型，统一约 1.75 米，使用轻量关节摆动和职业配件。

世界中安排 12 名百姓、6 名货郎、4 名衙役，以及最多 10 名摊贩。摊贩站位从实际集市摊位推导，其他角色沿东西向街道往返；前进需通过世界碰撞与加载检查，遇阻折返。未加载区域不创建角色，视距外禁用并保留在最多 32 名角色的模型池中，每帧最多创建一个模型，28 米内更新肢体动画。角色零件已合并为 GPU 骨骼网格，离开世界统一释放；详见 [性能说明](performance.md)。

当前是环境人群原型，没有对话、交易、寻路绕障、角色间避让或存档日程；不阻挡玩家。暂停游戏时停止更新。下一步可添加驻足、交谈和分时活动，替换简单折返路线。
