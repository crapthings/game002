# 世界规划调试

独立路由 `#/world-plan`，开始菜单提供入口。轻量 SVG 俯视图显示 512 米世界边界、区域覆盖色、聚落边界与功能街区；可开关道路、名称和子生态范围。点击区域或右侧列表查看面积、占比、建筑与街区数量，并聚焦该区域。

使用与游戏一致的 generateWorld 函数，在专用 Worker 中按 seed 生成规划；路由懒加载，无 Babylon 引擎、3D 模板或区块渲染。重新生成会终止前一个 Worker，退出页面释放 Worker。URL 查询参数保存 seed，可独立刷新或分享。

默认显示当前算法结果，不读取或写入 IndexedDB，不覆盖旧存档。如果本次会话已加载游戏，提供查看该游戏规划快照的按钮。快照结果可能来自旧版算法，界面标明来源。新世界以 32 m 精度采样生态及原始地形，可切换高度、坡度、湿度、建设适宜度；旧快照保留生态圈。道路仅显示规划线形。选中聚落可查看 49 个候选选址后的连通可建率、平均坡度、高差、标高及是否达标，详见 [分层规划](hierarchical-world.md)。
