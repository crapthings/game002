# 民宅财富分档

新增 12 款民宅，连同原有 8 款共 20 款。贫寒：柴棚小屋、补瓦陋居、巷尾匠户；普通：两开间、偏厦人家、阁楼人家；小康：三合小院、商住楼、花庭宅；富户：朱门深院、藏书宅、雅园别业。

财富通过泥灰墙与修补、开间和层数、侧厢或三合院、院门、盆景、书案与亭子体现。材质与结构共用工厂，模型仍按材质合并并实例化。偏厦碰撞只包含两面房舍，三合院包含三面房舍，院内保留通路。

住宅地块先按位置和种子分配财富，再选模型。外围住宅更偏贫寒和普通，其他住宅提高小康比例。小康与富户保留整格，避免小户型双铺筛选排除大宅；选择时尽量避开最近三次出现的民宅。财富只是建筑规划标签，不表示已有居民经济模拟。

生成器 v10、城市配方 v4，旧命名空间保留。资产目录已可查看全部模型；检查了富户院落预览、JavaScript 语法和 diff 空白。按 AGENTS.md 未运行测试、build、lint。


## 民宅立面 polish

20 款民宅分别配置墙色、瓦色、屋脊起伏以及木板窗、直棂窗、格栅窗、圆窗；配置位于 `residenceFacades`。

- 门窗按柱间净宽布置，正反面构件朝外；側窗整体旋转，避免窗棂埋进墙里。
- 合院左右厢房朝院内，正屋入口避开厢房占位；桃花别院改为不相交的 L 形侧厢，碰撞继续使用 layout 分体规则。
- 两开间与柳巷连宅采用分户入口，移除叠加的中央门；民宅取消统一店铺牌匾。
- 山墙沿瓦面采样封口；双层民宅采用层间短檐和楼板封边，避免屋脊穿入二层侧窗。
- 阳台区分窄挑台与通长栏廊，部分二楼门、晾衣架、院内书案、花树、柴棚和补瓦各有配置。
- 米制主体宽深与资产 ID 不变；继续按材质合并并共享建筑模板，没有每帧新增几何生成。
