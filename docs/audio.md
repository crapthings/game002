# 动作音效

`createGameAudio` 管理单个场景的 Web Audio 上下文、主音量、短音源缓存和最多 10 个同时播放的声音。当前使用本地生成的 PCM：鞋底低频触地与细碎摩擦、草地软声、木桥空腔音、瓦面脆声、起跳/二段跳/蹬墙/dash 破风以及落地冲击。无需网络请求、外部音源授权或解码等待。后续可替换 buffer 音源，保留动作事件与生命周期管理。

- 步行每 1.2 米、跑步每 1.65 米触发脚步；跑步更响、节奏随实际位移加快。贴墙动作计入垂直位移。
- 原地顶墙、空中、暂停时不播普通脚步；落地响度随冲击速度变化。每帧最多一个脚步，不补播积压。
- 运动控制器输出明确的 jumpEvent / dashStarted，避免根据持续按键重复播放。两段跳、蹬墙和冲刺分别触发。
- 音频在可信的按键/点击事件中创建并恢复，未解锁时不排队补播。静音和音量保存在 game002:audio:v1；暂停菜单提供控制。
- 切换地图/调试/暂停、窗口失焦和页面隐藏会停止短音；场景切换重置节奏，销毁时关闭上下文、解除监听并释放缓存。
- 地表分类在脚步触发时才查询，使用道路采样与桥梁资产；高于地面的支撑面暂统一使用瓦面音色。

验证：遵循 AGENTS.md 未运行测试、build、lint。JavaScript 语法、diff 空白检查与浏览器加载检查；未进行扬声器实际试听和完整操作验收。
