# 512×512 米自然世界

世界范围 X/Z 均为 [-256, 256)，中心为 (0, 0)，保留 1 unit = 1 meter、原角色与自然素材比例。中央 320 米规划区及外围八个区域继续保留，中央区域标记为 reserved，供后续武侠城镇规划；本阶段不生成建筑、道路、道具或敌人。

自然地形使用 8×8 生态单元、32 米流式区块和 1 米地面顶点间距。玩家从中心出发，使用键盘移动、两段跳与第三人称环绕视角。

生成器 v7 使用独立存储：game002-worlds-512-v7、game002:world:512:v7:、game002:active-seed:512:v7。旧版本存档保留在原命名空间，不加载已经删除的资产或覆盖原进度。

外围城防见 [四方城防](fortifications.md)，中心线距世界中心 192 米，四门连通城内外。

城内四层生成、街巷与水桥见 [城内四层生成](city-hierarchy.md)。
