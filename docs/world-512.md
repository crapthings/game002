# 512×512 米世界

世界边长为 512 米，X/Z 坐标范围为 [-256, 256)，总面积 262,144 平方米。玩家移动、区块流式加载、道路寻路和实体出生都使用该边界。

保持 1 unit = 1 meter；角色、建筑、自然素材、道路宽度、移动速度、相机距离、32 米区块和 16 米道路寻路精度不变。缩小世界覆盖面积，不整体缩放场景素材。

城市中心固定在世界坐标 (0, 0)，对应从地图左下角计量的 (256, 256)。中央规划区为 320×320 米，其余八片城郊区域覆盖世界边缘。使用已有中城规划尺寸（主体跨度 256 米，16 个街区），建筑、道路等素材本身不缩放。原村庄、小城和大城的素材与生成器保留，但本版只生成一座中央城市。

城市按离中心的距离由近及远布置街区。中心保留商业与公共设施；外围布置住宅、边缘工业和公园，外围建筑覆盖率与候选填充概率降为原配置的 65%。两条中央主干道贯通城市，支路连接内外街区，环路围绕外围；四向出口延伸到距世界边界 32 米处。出生点设在中心主路交叉口。

生态细分仍为 8×8 个 64 米单元，单元按实际位置寻找所属区域，支持中央城区跨越多个宏观生态区。固定城心仍采样地形标高并沿用聚落整地，不再随机选择城市位置。

生成器升级至 v4。IndexedDB 使用 game002-worlds-512-v4；localStorage 使用 game002:world:512:v4: 与 game002:active-seed:512:v4。旧版 2048 米世界和 v3 象限布局存档保留在原存储空间，不自动导入或覆盖。相同种子首次进入新版会生成新的小世界并创建新进度。

地图、菜单和规划预览同步显示新尺寸。现有素材和玩法仍保留，武侠内容另行迭代。
