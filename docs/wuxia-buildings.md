# 清明江湖建筑资产

新增 18 种可实例化的程序化建筑，在「资产目录 → 武侠建筑」预览。参考青瓦木构庭院的形制，使用浅青瓦、暖白墙、木色立柱、曲面瓦垄、灯笼、石阶和花木；保持 1 米单位和 1.8 米玩家比例。这批是风格化外观资产，不是参考图的写实贴图复刻。

- 通宝当铺：高柜、铜钱徽记。
- 百草药铺：百子柜、药罐、晒药盘。
- 春溪小筑：单层民宅、竹篱。
- 临风绣楼：双层民宅、阳台。
- 青竹合院：三面围合民宅、石径。
- 桃花别院：侧屋、桃花点景。
- 锻雪兵器铺：剑架、铁砧、锻炉。
- 听雨客栈：双层长廊、桌凳。
- 清风茶楼：茶棚、青瓷茶具。
- 杏花酒肆：杏色布棚、酒缸。
- 云锦绸庄：彩色布匹。
- 明心书院：书架、石灯。
- 长风镖局：旗杆、货箱。
- 栖霞祠堂：重檐、香炉、石灯。

屋面和瓦垄使用同一曲线采样。构件按材质合并成共享模板，实例复用几何体，不添加逐建筑动态灯光或更新循环。定义包含尺寸、行业标签、占地信息。已接入 v7 城内四层规划。新增枕水人家、晒谷人家、柳巷连宅、书香小院四种民宅；合院拆分三面房舍碰撞。当前未提供室内经营交互。
