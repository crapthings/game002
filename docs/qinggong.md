# 轻功与屋顶移动

空格起跳，再按一次二段借力。按住空格上升更充分，松开收势；一段长按理论升高约 5.06 米，二段单独贡献约 4.34 米（需要在一段接近顶点时触发）。空中方向键调整落点，双击方向 dash 仍保持短暂滞空。

靠近建筑墙面或城墙时，空中按住空格和方向：朝墙攀升，沿墙方向跑动。松开再按空格蹬墙，向外弹开并保留一次空中借力。一次腾空共享 1.65 秒贴墙预算，蹬墙也扣除预算，落地/屋顶恢复。蹬离后 0.25 秒保护，避免输入立刻抵消推离速度。跑墙附带侧倾与交替踏步，攀墙附带抬手动作。

`createTraversal.js` 在加载区块的碰撞数据上提供高度查询、带高度阻挡和墙面法线。民宅正屋与侧厢分别建模，屋面沿现有 6 段瓦面剖面采样。屋檐可落脚，墙身仍阻挡；建筑模板缩放和旋转同步作用于碰撞。城墙主体支持上城和沿城墙行走，女墙单独抬高支撑高度。自然物体仍保留圆形阻挡，NPC 继续使用平面导航。

当前是基础轻功控制器：没有抓檐悬挂、自动翻越、转角吸附；城门楼和角楼暂时保留阻挡，未配置各层可落脚面。商铺的特殊叠加小屋顶与附属棚架没有逐构件碰撞。没有每帧对全场景美术三角网格做射线检测。
