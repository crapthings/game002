# 侠客与两段跳

玩家使用程序化低多边形侠客模型：宽檐编织斗笠、束发与散发、墨青交领布衣、腰带、护腕、布鞋和分片深色披风。双手空置，不配武器。沿用原角色高度基准与碰撞半径；翻滚围绕视觉模型腰部，不旋转物理根节点。原幸存者模型保存在 createSurvivor.js，并以 character.survivor 登记在资产目录。

操作：空格起跳，松开后再按空格二段跳；按住不会自动连续跳。短按降低跳高，长按保留上升速度；空中第三次按键不会产生额外跳跃。离地宽容 100ms，跳跃输入缓冲 120ms，落地恢复跳跃次数。暂停/面板/失焦清空输入，不重置空中次数。

第一段起跳速度 7.8m/s、第二段 8.6m/s，上升重力 24m/s²、下落重力 34m/s²，下落限速 24m/s。第二段会重置上升速度，不与当前垂直速度叠加。物理使用不超过 1/120 秒子步积分；地面加减速、空中惯性与转向控制独立。模型包含空中收腿、0.48 秒前空翻、落地压身、披风/发束/衣摆摆动。镜头高度采用平滑追随，地面投影随高度淡出。

本版跳跃落在地形表面，继续沿用原有建筑与物件的平面阻挡，因此不能穿墙，也未加入屋顶站立、翻墙、攀爬或摔落伤害。存档仍保存地面 X/Z；退出后再次进入时回到该位置地面，不恢复半空状态。
