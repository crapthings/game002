# 当前架构

React 页面与 Zustand 状态管理承载菜单、侠客状态、图形配置、探索地图和开发面板。Babylon 场景负责第三人称相机、侠客模型、两段跳、光照与自然区块渲染。

资产目录仅登记自然生态和侠客。自然部件与变体位于 assets/nature，通用环境模型由 assets/environment 渲染；角色动画与物理控制独立。旧现代建筑、道路外观、生存道具和旧角色已移除。

世界维持 512×512 米，由中心规划区域和外围八区构成，当前只生成自然内容。Worker 生成地形，主线程分帧安装；图形视距控制附近区块，保留碰撞与边界限制。进度保存位置、探索迷雾、体力与世界时间，旧存档独立保留。

操作：WASD / 方向键移动，Shift 奔跑，空格两段跳，左键环绕，滚轮缩放，M 地图，Esc 暂停，F2 开发面板。左键不再控制角色移动。
