## 统一走查顺序

下表为验收步骤，已收到的实测证据见文末，其余仍待验收。为比较不同选择，可使用不同世界种子；不要删除旧存档。进入城中心十字街南侧，等待六名带名字的角色和药包出现。

| 项目 | 操作 | 应观察到的结果 |
|---|---|---|
| 初始化 | 新v10世界进入中心区域 | 100文、60气血、一份干粮、6件容量，六名参与者；无可行布局时明确等待 |
| 购买/出售 | 买一份15文止血药，再卖一份7文止血药 | 玩家100→85→92文；商人60→75→68文；药库存4→3→4，玩家药0→1→0 |
| 使用 | 初始使用一份干粮 | 气血60→70，干粮1→0；没有物品不消费，满气血不消费 |
| 容量与财产权 | 买满背包，再尝试拿涉案药包；卖出后重试 | 满包拒绝拿取；涉案药包占一格，但不能使用、出售或救人 |
| 明脸拿取 | 在角色面前按E | 目击证据包含身份；举报人实际靠近捕快后才建立报告与追踪 |
| 匿名对照 | 另一轮按H蒙面后拿取 | 有目击时仅记匿名身份，无具名追捕；无人看见时无举报 |
| 追踪 | 具名报告后离开视线/蒙面 | 不再更新玩家位置；旧位置追踪15秒后停止，案件仍保留 |
| 结案 | 靠近捕快按R，多按一次 | 只赔偿20文一次；药包先由捕快代持，实际送回后才显示在摊位 |
| 善意链 | 买药，未蒙面靠近柳娘按F | 药减少1，信任25；至少20模拟秒后柳娘实际认出并靠近才回礼15文 |
| 匿名善意 | 另一轮蒙面救助 | 药消耗、伤势改善；不增加具名信任、不定向付款 |
| 保存恢复 | 举报途中、交还后、回礼前后分别暂停再进入同种子 | 位置/案件/资金/物品恢复；不重复举报、赔偿或回礼 |
| 交互边界 | 隔墙/空中/未加载时尝试交互；操作HUD控件 | 不隔墙交易或拿取；按钮空格不跳跃，选择框方向键不移动 |
| 因果回顾 | 选择拿取/救助链，点击原因与后续，展开角色知识 | 关联正确，匿名不变具名；未获消息的角色没有对应知识；回顾不改状态 |
| 暂停及冲突 | 暂停等待；另页更新同种子后尝试保存 | 暂停不推进模拟；冲突提示且不覆盖别页进度 |

保存成功应以实际重新进入后的状态为证据；仅看到按钮反馈不算存档验证。强制关闭页面可能只恢复最近成功检查点。v9不会自动迁移到v10。

案件恢复校验补充：案件的举报人、目击依据、送达记录和状态必须与事件账本逐项一致。已有report但案件清空reportEvent、已有目击却丢失举报人、重复同人同案目击，均应拒绝恢复，保留原数据。此校验已编写，损坏快照恢复与正常快照回归仍待验收。
