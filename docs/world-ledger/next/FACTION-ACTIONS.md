# 05-B：组织行动实施契约

基线 acb9ed9。状态 REVIEWED；下列为已接代码与源码追踪边界，不是运行证明。09-B 的拘押流程仍按后续卡片实施。

## 报案和支援

显式启用 factions.actionsVersion=1。报案意图引用本人当前 evidenceId，保存 seeking / waiting / delivered；具名或匿名主体完全继承原认知。只能交给实际见到、接近且可用的在职捕快。看不见时前往固定府衙服务点，不查询捕快实时位置当目的地；无人接待保留意图，等待后恢复日常并定时再尝试。

援助者从真实的职责成员中挑选，不新刷捕快。发送人依据自己的送达回执去重，不读取另一个人的知识来决定自己是否已经说过。对犯罪的严重度和合法防卫判断继续由原 crime/forcePolicy 负责。

## 调解和费用

调解必须由确有该案个人证据的捕快当面处理。案件键为 incidentId + victimId，其他侵害不连带清除。药包的原20文、实际药包交接及物主收款保留；一般轻案报价和财物追偿明确列出，致命案件不允许付一笔小钱直接消失。

钱包和财物只在原 interactions 中变化；缺钱、财物未能归还或不能确认身份时不部分扣费。处理人员中止本次执法动作需有该案处理依据，不能清除另一未结案的合法追捕。

## 有限组织资源

公共悬赏引用经手人本人已获证据的案件，奖励先从原钱包预留。缺资源保留等待原因，不凭空筹款。支付需要可追溯的实际捕获/处理事实；09-B 的真实拘押结果可作为兑现来源，禁止凭靠近坐标或死亡次数领奖。赔偿结案与捕获奖励分别有原回执；被强取的预留会受损。

商会沿用现有采购、货款和运输所有权；护送额外约定必须引用真实承运合同、独立预留报酬，并记录实际接洽和随行，不能只在两端出现就奖励。NPC 自主承接与玩家交互共享同一事实和资金条件。

帮派本期只做实名当面请求及有限的受理/拒绝入口，完整保护费、地盘战争不在此卡。发起请求本身不把匿名旧案的真实人物身份告诉帮派，也不触发自动谋杀或随意扣钱。

## 展示和审阅

本人会话/已知任务显示费用、等待原因与可行下一步；不把全城案件、资金和成员坐标暴露给普通 HUD。createLivingStateIndex 随不可变状态重建职责、送达及案件查询。冻结 v1 不修改，旧 v2 依赖新领域显式启用来保持重放。

按报案→逐案调解→悬赏→护送→请求入口接入，逐项源码追踪。当前禁止运行测试/build/lint；任何实际接洽、失去视线、重复请求、欠款、跨档或性能通过的结论必须另有运行证据。

## 当前实现到哪里

已接显式启用、个人证据报案意图、现场选择可用捕快、固定接案处/等待后重试、自己的送达回执去重。职责查询按状态缓存重新构建。原路径只用于尚未启用该版本的状态。

已接轻案当面赔偿：1/2级侵害的赔偿目标为10/20文；之前同一侵害已经付过的赔偿抵扣，实际强取的铜钱按原 claim 未偿额另还，搜取的物品按仍持有原 lot 归还合法所有人。本人收手、捕快看清身份后才可以交易；缺款、原物找不到或归属待核对时整笔不发生。金额进入真实受偿钱包，物品不复制。

结案按 incidentId + victimId + 已处理严重度生效。稍后取得更严重的证据会重新打开这部分责任，原赔款仍保留；同一回执不重复计费。3级案件等待09-B拘押流程。仅收到赔偿的捕快会按剩余案件决定是否立即放下本次武器；其他侵害继续存在。

当面付款人和经办捕快得到本次赔偿事实的真实记忆；商会成员要听到这条有来源的消息，才解除对应个人交易拒绝。不会因为其他成员知道了某事就统一变脸。药包仍走原20文/物主收款路径，现可由实际接近的在职捕快接收并亲自送回。

悬赏由经手捕快到真实府衙地点张贴，5文先从本人钱包预留；缺钱记录等待，有钱后仍需亲自回到接案处补足。告示需亲自阅读，支援会面也可携带发起人本人的已出资约定。读过的告示保留当时条款，不显示远处实时撤回状态。09-B 的 `continuity.custodies` / `taken_into_custody` 必须含本人、当事人、对应案件与捕获事实；先捕获再读告示不能补领奖资格。同一次处理涉及不同受害人案件可各自核销其独立5文预留；同一案件只有一份悬赏和一次支付。本人办自己的赏单仅释放预留，不发给自己额外收入。实际完成的拘押在后续结案或资金受损后仍保留待付责任，不因结案删掉赏钱。

当面调解后先关闭经办人的对应记录；其他捕快仍按自己的证据行动，取得有来源的结案回执后才关闭自己的对应案件。商人也要获知此回执才解除该件侵害的拒绝。稍后更严重的事实可重新立案，已经交还的财物和赔款不会重复计算。

护送由启用后真实的采购接单会面产生：在货款/跑腿费已经预留后，商人还有3文才另约同行照应，同一采购只产生一单、城内同时最多两单。条款由掌柜当面告知；一人承接，不能同时给自己护送，也不能与另一项在办差事争抢同一 NPC。承运人装货后在现场等最多一个游戏小时，期限仍受原采购合同限制。护送者必须在装货处实际接洽，再在6米/无遮挡范围随行；每模拟秒记下一次观察，连续缺席超过2.5模拟秒中止。只计实际货物取出后的移动，至少3模拟秒且8米，并亲见这批货物交抵；两端出现不能代替过程。数值为首版固定规则，后续调整须保持旧规则重放。

玩家和 NPC 使用同一接单、接洽、随行、送达与付款命令；NPC 只前往记住的固定地址、眼前承运人或刚才真正看到的位置。送达后报酬成为待付责任，需当面结清一次；缺钱仍保留。货物和采购报酬保持原采购合同唯一状态，护送不会复制货物。护送进度是个人记忆，远处取消/死亡不会自动变成每个参与者的消息；自己走散、超时或到场看到送达不满足约定会留下自身结果。05-B的护送不自动安排袭击者；NPC对非玩家攻击者的泛化战斗不在本卡新增。

渡口赵六可听取本人具名证据并登记警告请求；涉及同帮成员会拒绝，否则只记下说法，没有付费和执行暴力承诺。转述保留原证据链，已转述过的同一依据复用原回执。本期有限请求入口不是保护费/地盘战争系统。

新增领域均显式启用；冻结 v1 不变。新护送采样事件按归档页规则保留原页和必要索引，未改变旧事件种类的淘汰规则。源码审阅覆盖领域路由、现场适配、钱物/预留、个人记忆、职责缓存和归档编号；没有运行测试/build/lint、浏览器玩法、跨档或性能验收。09-B仍须接入真实拘押及悬赏兑现的后半程，不能把当前领奖证据接口当成拘押已实现。
