实施基线8dd8b29。当前只允许源码审阅，不运行测试/build/lint；这里的约定不是运行证明。

11-A在显式启用后记录种子、日期、参与者和原场所。熟人寒暄可发生于实际相遇的安全白天场所，只说短句；茶摊驻足使用街心原公共会面点，实际在场才开始和结束，不凭空生成茶或恢复气血。邻里帮运需要物主亲自将一份可支配的原干粮交给熟人，双方按原住处地址走路，到场再交回；所有权不变，原背包和库存会真实变化。

同类型每对人物每游戏日最多一次，全部事件共享5游戏分钟的发起间隔；稳定选择只由保存的种子、游戏日和参与者确定。旧存档不重新抽取。正向变化只在真实完成帮运、物主亲自知道回执时发生；路人不会凭空增加好感。伤害、死亡、急需吃饭、已有委托、当前战斗和真实玩家交谈优先。

茶摊停留6模拟秒；搬运约定最多2游戏小时。自己的打断只结束自己的参与，另一人仍依据原约定/亲眼见到的离开/期限行事。物主不在时保留原物，不能因取消把货瞬移回库。菜单保存停止短暂闲谈；搬运保留原物、原约定地点和未完进度。

11-A已接`gameplay/dailyActivities.js`、`living/socialActivities.js`和配置。公共会面点登记为街心茶摊，用原几何落点，不新增建筑。发起条件要求双方实际在一起、相互熟识、身体与需求可支持且没有更优先的约定。打断自己的参与会结清当前需求区间并暂停工时；搬运中仍是原物主所有的一份干粮。交回时物主获得直接回执，沿已有唯一关系数据增加2信任/恩情，不能靠查看全局事实获得。

原物来不及交回会保留待还状态。帮手在有空且状态允许时，间隔一游戏小时再次去原约定地点找接收人，一次最多寻找一小时；没有遇到就恢复原生活。死亡不消失物品，若后来实际遇到具名保管人，可按09-B的现场权限交还。保存恢复沿原参与状态与物品记录继续，不再创建同日同一活动。

11-B已接`living/attentionQueue.js`和`attentionMessages.js`：只接玩家亲历、当面告知或当前实际看见的事件。危险/本人操作失败为第一优先，委托及个人回执随后，当面消息和普通活动依次排队。远处NPC命令的普通失败不向玩家弹报；保存失败仍立即提示。

主动提示最多一条，危险可替换低优先提示；普通消息在自己或眼前人物交战时延后，彼此至少间隔20模拟秒。按同源去重、同组20秒内合并，已显示的普通提示不持续换文字突破间隔。显示6秒；等待时按类别15/60/90秒过时，过时只影响提醒。待提醒上限24条，最近列表80条；原账本与个人委托记录不随列表裁剪。列表可以收起提示、按最近来源打开事后回顾。

提示队列作为可选展示数据随原living检查点保存，不增加另一个世界时钟或改变玩法快照。旧档缺少此字段时从空列表开始；字段存在时检查版本、编号、时序和单一活动提示。菜单中不推进提示时间。事务先确认玩法保存再发提示，因此异常退出紧接最新交易时，最近一条尚未再次保存的提示可能缺失；真实交易与因果记录仍在确认后的玩法档内，可从原回顾查询。
