2026-09-08：由当前持续 Goal 统一实现。状态为源码已编写和审阅，尚未运行测试、build、lint 或新场景验收；不能把本文当成实机通过证明。整个 29 卡 Goal 仍 active。

## 玩家可见变化

- 新世界七人按药铺、府衙、住处和中心商区分布。阿青在药铺街侧活动，林岳跨河巡逻；其余人在办事结束后返回自己的归属点。
- 入口街侧有“街坊便笺”。2 米内面向便笺按 E，可记下五处固定地点；在柳娘身边询问也能得到药铺地址。地图与行囊可选择地点指引，仍须亲自接近人物交易或救助。
- 地图标记来自到访或明确告知，空心点周边仍保留迷雾。标记是通常活动地点；只有当场看到本人才能显示“已看到本人”。
- 已有药包举报、交还送回、救助回礼继续走原规则。人物远离玩家时仍可沿真实道路办事；没有增加远处随机攻击或虚构目击。

## 旧档与事务

1. 完整恢复验证旧 gameplay v1 日志后，扩展 living 布局封装。旧七人/物品配置、configSignature、原 legacy、财物、案件和回礼记录不重建。
2. living v1 继续可读；新写 living v2 / document schema 4，旧读者会拒绝新版。已有 NPC 坐标与尸体保持原处，闲置活人走到新地点。
3. 原摊位上的药包由活着的物主实际取走、走到新摊位再送达。两步有稳定 operationId 和事实；不触发盗窃。搬运途中死亡，财物仍在该人物实际容器。
4. 药包已被玩家/捕快持有时，只更新空摊位目的地；不修改物品持有者。完成送达的摊位坐标与物品转移进入同一个检查点，保存确认后才更新场景。
5. 旅行只存目的地/状态，不存 Worker 或 Mesh。读档重建路径；暂停、保存期间不推进位置和模拟时间。保存异常沿用原有停止提交和重新读取行为。
