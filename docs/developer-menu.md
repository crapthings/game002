# 开发菜单与地图瞬移

F2 打开开发菜单。地图全显、无限奔跑、奔跑倍率和地图瞬移开关自动保存到 localStorage 的 game002:debug:v1，刷新或重新进入后恢复。仅保存白名单字段并校验类型；恢复默认同时更新本地记录。存储不可用时仍支持本次会话。

开启「地图瞬移」后，M 地图单击目标位置即可请求传送。移动超过 6 像素视为拖动，取消指针不会传送，边界外点击会提示。全域、缩放和平移均使用当前地图比例换算 X/Z。加载中拒绝重复请求，并显示进度和取消按钮；关闭地图或关闭瞬移模式也会取消。

角色保留原位置，先按当前图形视距准备目标区块。沿用单 Worker 任务队列，主线程安装每帧软预算 2ms，旧区块分帧释放，不生成全图。区域就绪后，从点击位置向外最多搜索 24 米；每帧最多 16 个候选并限制 2ms。超过 45 秒或找不到安全空地时取消，不移动角色。

落点要求附近区块已加载、距世界边界至少 3 米、脚下平坦、1.1 米余量内无碰撞或视觉包围盒遮挡。视觉包围盒在资产实例创建时缓存，用于避开树冠、高灌木和岩石，低于 0.35 米的草花不阻止落地。候选通过后，角色从地面上方 10 米开始自然下落，清空旧惯性和按键，立即重置镜头跟随位置。地图关闭后按原物理重力落地，并保存新坐标。

瞬移请求不持久化；偏好设置不混入世界存档。地图全显不写入探索记录，瞬移只记录目标附近探索，不揭开起终点之间的路径。
